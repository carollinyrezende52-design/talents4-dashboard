# Talents 4 · CRM (produção)

CRM de recrutamento internacional da Talents 4: Talentos, Empregadores, vagas, seleções, apresentações, contatos, agenda, acompanhamento de Alemão, planejamento organizacional, Documentação e Configurações (gestão de usuários).

Este é o site em produção, usado no dia a dia pela equipe. Não é necessário instalar nada — basta abrir a página publicada no navegador e entrar com seu usuário.

## Estrutura deste repositório

- `index.html` — tela de Talentos (candidatos, empregadores, vagas, seleções).
- `organizacional.html` — planejamento organizacional.
- `contatos.html` — contatos e agenda.
- `alemao.html` — acompanhamento do curso de Alemão.
- `documentacao.html` — documentação de processos.
- `configuracoes.html` — configurações e gestão de usuários.
- `manual-talentos.html` — manual de uso da tela de Talentos.
- `assets/` — todo o código do site (HTML/CSS/JS), sem etapa de build.

## Sobre alterações no sistema

O desenvolvimento e os testes de novas funcionalidades acontecem separadamente, antes de qualquer mudança chegar até aqui. Este repositório reflete sempre a versão que está no ar para os usuários.
